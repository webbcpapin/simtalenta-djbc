# Panduan simulasi

1. Pilih jumlah latihan, jumlah soal ujian, waktu, domain, subdomain, dan kesulitan.
2. Gunakan Pembahasan Langsung untuk belajar; alasan A–D dan uraian topik terbuka setelah memilih.
3. Gunakan Simulasi Penuh untuk kondisi ujian; pembahasan terbuka setelah paket dikumpulkan.
4. Tandai `Ragu` untuk navigasi dan `Favorit` untuk membuat paket ulang khusus.
5. Setelah selesai, baca skor per domain, kesulitan, dan level kognitif; ulangi soal salah/kosong.
6. Riwayat, progres, favorit, serta sesi aktif tersimpan lokal dan tidak dikirim ke server.

Paket memakai seed baru, menghindari sampai 300 ID yang baru dilihat bila bank mencukupi, dan menyusun distribusi berimbang. Alat ini untuk belajar mandiri, bukan penetapan kelulusan resmi.

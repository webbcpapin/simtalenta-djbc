# Panduan simulasi

1. Pilih jumlah latihan, jumlah soal ujian, waktu, kelompok sumber, subdomain, dan kesulitan.
2. Pilih kartu kategori pada bagian **Peta Materi** untuk latihan terfokus. Tersedia 100–180 soal pada setiap kategori.
3. Gunakan **Pembahasan Langsung** untuk belajar. Setelah menjawab, alasan pilihan benar dan kondisi yang membuat tiga pilihan lain dapat tepat langsung terbuka.
4. Gunakan **Simulasi Penuh** untuk kondisi ujian; pembahasan terbuka setelah paket dikumpulkan.
5. Tandai **Ragu** untuk navigasi dan **Favorit** untuk membuat paket ulang khusus.
6. Setelah selesai, baca skor per kategori, kesulitan, dan level kognitif; ulangi soal salah atau kosong.
7. Riwayat, progres, favorit, serta sesi aktif tersimpan lokal dan tidak dikirim ke server.

Paket memakai seed baru, menghindari sampai 300 ID yang baru dilihat bila bank mencukupi, dan menyusun distribusi berimbang. Alat ini untuk belajar mandiri, bukan penetapan kelulusan resmi.
